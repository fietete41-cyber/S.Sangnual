# ส.แสงนวล ผลไม้ — ระบบสต็อก + บันทึกการขาย

เว็บแอปหน้าเดียว แทนการจดสมุด/กดเครื่องคิดเลขเอง
กรอกแค่ **จำนวนลัง** กับ **ราคา/โล** แล้วระบบคิด `ลัง × โล/ลัง (+แถม) = โลรวม × ราคา = ยอดเงิน` ให้อัตโนมัติ
รวมยอดขาย–ทุน–กำไร รายวัน/เดือน/ปี, ตัดสต็อกให้เอง, เก็บบิลค้างชำระ

## ไฟล์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวแอป เปิดใช้ได้เลย (ดับเบิลคลิก หรือเอาขึ้นเว็บ) |
| `Code.gs` | โค้ดหลังบ้าน สำหรับเก็บข้อมูลใน Google Sheet (ใช้หลายเครื่อง) |

---

## เริ่มใช้ทันที (ไม่ต้องตั้งอะไร)

เปิด `index.html` ได้เลย — ข้อมูลจะเก็บไว้ **ในเครื่องนั้น** (เบราว์เซอร์เดียว)
เหมาะกับลองใช้ก่อน แล้วค่อยเชื่อม Google Sheet ทีหลัง

> ถ้าจะเปิดจากมือถือ ให้เอา `index.html` ขึ้น GitHub Pages / Netlify แล้วเปิดลิงก์นั้น

## เชื่อม Google Sheet (ใช้ร่วมกันหลายเครื่อง — ทำครั้งเดียว)

1. สร้าง **Google Sheet ใหม่** 1 ไฟล์
2. เมนู **Extensions → Apps Script**
3. ลบโค้ดเดิมทั้งหมด แล้ววางเนื้อหาจาก `Code.gs` → กด 💾
4. *(ถ้าต้องการรหัสผ่าน)* ⚙️ **Project Settings → Script properties → Add** : `PIN` = `1234`
5. เมนู **Run** เลือกฟังก์ชัน **`setup`** แล้วกด Run — ครั้งแรกจะขึ้นให้กด **Authorize / Allow**
   → ระบบจะสร้างชีต `สต็อก` `การขาย` `ทุนรายวัน` `ปรับสต็อก` พร้อมตัวอย่างให้
6. **Deploy → New deployment → ⚙️ เลือก Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด **Deploy** แล้ว **คัดลอก URL** ที่ลงท้ายด้วย `/exec`
7. เปิดแอป → แท็บ **ตั้งค่า** → วาง URL + PIN → **บันทึก & เชื่อมต่อ**

เสร็จแล้ว เปิดแอปจากเครื่องไหนก็เห็นข้อมูลชุดเดียวกัน (ข้อมูลอยู่ในชีตของคุณ)

> **มีข้อมูลที่กรอกในเครื่องไว้ก่อนแล้ว?** หลังเชื่อมต่อ ไปที่ ตั้งค่า → “อัปโหลดข้อมูลในเครื่อง → Google Sheet”

### เวลาแก้โค้ด `Code.gs` ภายหลัง
**Deploy → Manage deployments → ✏️ (ดินสอ) → Version: New version → Deploy** (URL เดิมไม่เปลี่ยน)

## วิธีใช้งาน

- **แท็บ ขาย** — เลือกรอบ/ปลายทาง/ลูกค้า, กดเพิ่มรายการ, ใส่ลัง + ราคา/โล (เว้นว่างได้ถ้าใช้ราคาเริ่มต้นของสินค้า), แถมโลได้, ยอดเงินแก้ทับได้ → บันทึก แล้วระบบตัดสต็อกให้
- **แท็บ สต็อก** — เพิ่ม/แก้สินค้า, ตั้ง “โล/ลัง” “ราคา/โล” “ทุน/โล” และจุดเตือนของใกล้หมด, ปุ่ม รับเข้า/ตัดออก
  - **เพิ่มหลายรายการเร็ว ๆ** — พิมพ์ชื่อผลไม้บรรทัดละ 1 อย่าง (ใส่ `, ราคา/โล, โล/ลัง` ต่อท้ายได้) แล้วกด “เพิ่มทั้งหมด” ทีเดียว
  - หรือระหว่างออกบิลในแท็บ ขาย เลือก “**+ เพิ่มสินค้าใหม่…**” ในช่องเลือกสินค้าได้เลย
- **แท็บ สรุป** — รายวัน/เดือน/ปี : ยอดขายรวม, ทุน (กด “แก้ทุน” ใส่ยอดจริงได้), กำไร, แยกตามรอบ–ปลายทาง, แยกตามสินค้า, รายการบิลค้างชำระ (กด “จ่ายแล้ว” เพื่อเคลียร์)
- **แท็บ ตั้งค่า** — เชื่อม/ทดสอบ Google Sheet, โหลดข้อมูลใหม่, ดาวน์โหลดไฟล์สำรอง `.json`
